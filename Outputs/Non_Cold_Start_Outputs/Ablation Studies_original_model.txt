Stage 4
+ GMU Gating — add GMUGating (per-group sigmoid gate) — this is the stage where we check if gate values vary meaningfully
After attention has softmax-weighted each group, gating applies a per-group sigmoid gate — a learned value between 0 and 1
tests whether gating adds anything beyond what attention alone already does, since both mechanisms reweight groups — 
attention does it via a relative softmax across groups (weights sum to 1), while gating does it independently per group
 (each gate is its own unconstrained 0–1 value, not competing with the others).
