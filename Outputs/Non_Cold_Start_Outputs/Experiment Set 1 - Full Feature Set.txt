How to Run Each Time
--------------------

1. Navigate to your project root:
bashcd "C:\Users\T-Plug\Desktop\ML Mini Project\hybrid_churn_prediction_project"

2. Run it:
bashpython hybrid_train.py
That's it. It will train all three datasets automatically under whatever subset_name is set in __main__.

To switch experiments, open hybrid_train.py, find this line at the bottom:
pythonrun_all(
    subset_name="baseline",   # ← change this
    checkpoint_dir="checkpoints",
)
And change subset_name to whatever folder you want, e.g.:
pythonsubset_name="experiment_set2/1"
Then run python hybrid_train.py again. Everything else — input paths, groups.json, model save paths — updates automatically.



Checklist before each run:
--------------------------
Edit feature_engineering_defintions.py with the new feature config
Run python feature_engineering.py with the matching subset_name to generate the data
Change subset_name in hybrid_train.py to match
Run python hybrid_train.py
